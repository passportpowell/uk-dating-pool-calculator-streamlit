- Final post-review checks and GitHub remote SHA verification recorded in HANDOFF when complete. Git push does not certify a Vercel production deployment.

## Deliberate limits and rejected recommendations

No plausible data were promoted into official observations. Rescaling invented postgraduate rows, labelling an arbitrary uncertainty band statistical, and converting household/family totals into all-parenthood rates were rejected. Broader parenthood and co-parent counts require suitable joint evidence. Income remains a declared age-independent approximation. English-country or national proxies remain visible. Unused .env credentials were not removed or rotated; no credential is used, printed, mirrored or published. Renaming GitHub, deleting original archives and changing cloud/tailnet settings were unnecessary to the supported fixes.

The original third-party PDF remains local and linked; limited factual extraction and its original fingerprint are published. Existing MIT code license and upstream data rights are preserved. Historical audits intentionally remain unchanged, including their obsolete file pointers.
